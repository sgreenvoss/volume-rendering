Volume rendering, but slow. The initial plan was to try to get it running as fast as possible. However, for whatever reason, I was really having a hard time conceptualizing the ray-through-grid algorithm, so I relied on VTK functions to do the work for me (I found each point by calculating its position along the ray, then used vtkStaticCellLocator to find the cell and its data for me). I would expect to see improvement from doing it the right way. Then when moving to parallelize, many of the functions I was relying on were actually not thread safe, so I had to refactor to account for that. Overall I think I spent around 20-25 hours on this, most of which was waiting for it to run and then profiling/attempting to improve it.

To assist with building I provided my cmakelists file. Parameters (like file name, samples per ray, etc) can be set at the top of VolumeRendering.cxx.
